###Portfolio Project #3 — Fresh Bakery Website Layout
###📌 About the Project
A modern, responsive website layout for a bakery brand («Fresh Bakery»). Built with clean semantic HTML5, structured SCSS using BEM methodology, and flexible layouts with CSS Grid and Flexbox. Features interactive UI elements and media optimization (AVIF/WebP formats) implemented with Vanilla JavaScript and Gulp.
🛠 Tech Stack
 HTML5 (Semantic multi-page architecture)
 CSS3 / SCSS (BEM methodology, CSS Grid & Flexbox)
 JavaScript (Vanilla JS): DOM manipulation, event handling & UI interactivity
 Build Tool: Gulp
 Version Control: Git & GitHub
